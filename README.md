# 🐍 snake_c

A classic Snake game written in **C**, built with **ncurses** for Linux and **pdcurses** for Windows. Lightweight, terminal-based, and runs directly from the command line.

---

## 🎮 Gameplay

- Control the snake using **arrow keys**
- Eat food to grow longer
- Avoid hitting walls or yourself
- Press **`backspace`** to quit the game anytime
- There are two levels

---

## 💻 Platform Support

- ✅ **Linux** (uses `ncurses`)
- ✅ **Windows** (uses `pdcurses`)

---

## To play
- ./snake in linux
- launch snake.exe for Windows
